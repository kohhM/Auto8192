# Auto8192

Steamのゲーム「[1/8192](https://store.steampowered.com/app/3014150/18192/)」(Unreal Engine 5製)を自動周回するボットです。このボットを使って実際にゲームをクリアしました。

## ゲーム概要

「1/8192」は、2枚の扉から1枚を選び続けるだけのホラーゲームです。操作はWASDキーのみ(マウス不要)。扉の正解はランダムで、正解すると進捗を示す分数の分母が倍になっていきます(1/2 → 1/4 → 1/8 → ... → 1/4096)。分母4096到達後は「最初に戻ったように見せかける」演出を経て8192を目指す構成になっています。死亡すると必ず分数表示のない最初のマップに戻ります。

## 仕組み

処理の流れ:

1. **ステージ検知**: ゲーム画面をキャプチャし、OpenCVのテンプレートマッチングで現在の分母を判定します。文字表示のない最初のマップだけは、明るいピクセルの有無で判定します。
2. **レシピ実行**: 検知した分母に対応するAutoHotkeyスクリプト(「レシピ」)を実行し、キー入力を再現します。レシピはユーザー自身がRazer Synapseのマクロ機能等で録画し、手動でAutoHotkey v2形式に調整したものです。キー入力は`SendEvent`による押しっぱなし(`{key down}` → `Sleep` → `{key up}`)として再現する必要があり、単純なタップ連打の再生では移動が反映されません。
3. **結果検証**: レシピ実行後、分母が変化したかを再度キャプチャして確認します。

以下の3条件でのみ音による通知を発報し、実行を一時停止します。復帰はコンソールに`/start`と入力してEnterを押すことで行います。

- 対応するレシピが存在しない
- レシピを実行しても分母が変化しない
- 分母4096に到達した(4096→8192間の演出は自動化対象外のため、ここから先は手動プレイに切り替える)

ログファイルは作成せず、すべてCLIの標準出力に表示します。想定外の例外が発生してもプロセスは落とさず、同じ一時停止・通知の経路に合流します。

## セットアップ

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

別途、[AutoHotkey v2](https://www.autohotkey.com/)をインストールしてください。

## 使い方

### 本番実行

```
python main.py
```

ゲームウィンドウ(`L8192`)を起動した状態で実行してください。Ctrl+Cで終了します。

### 新しいステージのテンプレート追加

新しい分母に到達したら、その画面のスクリーンショットから分母表示部分を自動でトリミングしてテンプレート画像を追加できます。

```
python make_template.py templates\ss\2048.png 2048
```

`templates/{ステージ番号}.png`として保存されます。

## ディレクトリ構成

```
8192自動化/
├── requirements.txt      # mss, opencv-python, numpy, pywin32
├── config.py             # ウィンドウタイトル・キャプチャ領域・閾値などの定数
├── main.py                # エントリポイント
├── debug_play.py          # レシピ単体デバッグ用ハーネス
├── make_template.py       # テンプレート画像の自動トリミングツール
├── templates/             # 分母表示部分を切り出した参照画像(2.png, 4.png, ...)
├── ahk/                   # ステージごとのAutoHotkeyレシピ(play0002.ahk, play0004.ahk, ...)
└── src/
    ├── capture.py          # ゲームウィンドウのキャプチャ
    ├── stage_detect.py      # テンプレートマッチング+明るさ判定によるステージ検知
    ├── input_player.py      # AutoHotkeyの呼び出し
    ├── alerts.py             # 通知音
    └── orchestrator.py       # メインループ
```

## 注意事項

- 収録されている`ahk/play*.ahk`のキー入力タイミングは、このプロジェクトの作者の環境・実行速度に合わせて調整されたものです。他の環境や、ゲームのアップデート後に同じ結果を再現できる保証はありません。
- あくまで個人の検証・学習目的のツールです。
